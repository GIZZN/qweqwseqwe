# 🦀 Tauri + Next.js Приложение

## Описание
Десктопное приложение, созданное с помощью Tauri, с фронтендом на Next.js и бэкендом на Rust.

## Функциональность
- **Приветствие из Rust**: Демонстрирует вызов Rust функций из JavaScript
- **Файловые операции**: Чтение и запись файлов через Rust API
- **Современный UI**: Красивый интерфейс с Tailwind CSS

## Собранные файлы

### Основной исполняемый файл
```
src-tauri\target\release\app.exe (11 MB)
```
Это самостоятельный exe файл, который можно запускать напрямую без установки.

### Инсталляторы

#### NSIS Инсталлятор (Рекомендуется)
```
src-tauri\target\release\bundle\nsis\tauri-nextjs-app_0.1.0_x64-setup.exe (2.8 MB)
```

#### MSI Инсталлятор  
```
src-tauri\target\release\bundle\msi\tauri-nextjs-app_0.1.0_x64_en-US.msi
```

## Технологии
- **Frontend**: Next.js 15.3.4 + React 19 + TypeScript + Tailwind CSS
- **Backend**: Rust + Tauri 2.6.2  
- **Сборка**: Статический экспорт Next.js → Tauri bundle

## Команды разработки

### Разработка
```bash
npm run tauri:dev
```

### Сборка
```bash
npm run tauri:build  
```

### Только фронтенд
```bash
npm run dev    # Разработка
npm run build  # Сборка
```

## Системные требования
- Windows 10/11 x64
- Нет дополнительных зависимостей (все включено в exe)

## Запуск
1. **Простой способ**: Запустите `app.exe` напрямую
2. **С установкой**: Запустите один из инсталляторов (.exe или .msi)

Приложение откроется в отдельном окне как нативное десктопное приложение!
